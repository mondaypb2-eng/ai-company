# AI Company

บริษัทเอเจนต์ Claude 5 ตำแหน่ง (CEO, PM, Architect, Engineer, QA) ที่เขียนโค้ดจริงลงเครื่อง รันเทสต์จริง และวนแก้จนกว่า QA จะให้ผ่าน

## เริ่มใช้
ดับเบิลคลิก `start.bat` (หรือรัน `python company.py`) แล้วเบราว์เซอร์จะเปิด http://localhost:8765 ให้เอง

ต้องติดตั้ง Claude Code และล็อกอินไว้ก่อน (ต้องใช้คำสั่ง `claude` ได้) ส่วนตัวโปรแกรมใช้แค่ Python ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

ฉากออฟฟิศเป็นพิกเซลอาร์ต 8 บิต อยู่ในไฟล์ `pixel-office.js` กดปุ่ม "ดูเดโมแอนิเมชัน" เพื่อดูการทำงานทั้งรอบ เดโมนี้ไม่ใช้โควตา Claude

## ขั้นตอนการทำงาน
1. **CEO** เขียน `.company/SPEC.md` มีเป้าหมาย, stack ที่เลือก และเกณฑ์ตรวจรับ
2. **PM** เขียน `.company/TASKS.md`
3. **Architect** เขียน `.company/DESIGN.md` มีโครงไฟล์, ข้อมูล และดีไซน์ UI
4. **Engineer** เขียนโค้ดและเทสต์ แล้วรันจนเทสต์ผ่าน
5. **QA** รันเทสต์และรันโปรแกรมจริง จากนั้นเขียน `QA_REPORT.md` กับ `qa.json`
   - ไม่ผ่าน: Engineer แก้แล้วส่งตรวจใหม่ จนกว่าจะผ่านหรือครบจำนวนรอบที่ตั้งไว้
   - ผ่านแต่ยังมีจุดเล็ก: ทำรอบเก็บงานเพิ่มอีก 1 รอบ
6. **CEO** เขียน `README.md` แล้วส่งมอบงาน

ทุกโปรเจกต์อยู่ใน `projects/` ถ้าติ๊ก "สั่งงานเพิ่มในโปรเจกต์ที่เลือกอยู่" ทีมจะแก้หรือเพิ่มฟีเจอร์ในโปรเจกต์เดิม

## ข้อควรรู้
- ใช้โควตา Claude ของบัญชีคุณ งานหนึ่งชิ้นคิดเป็นเงินประมาณ $3–5 ถ้าอยากประหยัดให้เลือกทีม "Sonnet ทุกคน"
- เอเจนต์รันคำสั่งได้เองภายในโฟลเดอร์โปรเจกต์ (อนุญาตเฉพาะ Bash, PowerShell, Read, Write, Edit, Glob, Grep)
- เอเจนต์แต่ละตัวทำงานได้ไม่เกิน 25 นาทีต่อรอบ กด "หยุด" ได้ทุกเมื่อ
